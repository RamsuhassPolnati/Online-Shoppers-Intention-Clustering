
# Online Shoppers Intention Clustering

## Project Overview

This project focuses on segmenting online shoppers into different groups using unsupervised machine learning.

The K-Means Clustering algorithm is used to identify customer behavior patterns based on online shopping session data.

## Objectives

- Analyze online shopper behavior.
- Perform data preprocessing and feature engineering.
- Apply feature scaling.
- Determine the optimal number of clusters.
- Implement K-Means Clustering.
- Understand different customer segments.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithm

### K-Means Clustering

K-Means is an unsupervised machine learning algorithm that groups similar data points into clusters.

The project uses:
- Elbow Method
- Silhouette Score
- Feature Scaling
- K-Means Clustering

K-Means Clustering was applied to segment online shoppers based on their behavioral patterns.

The final model uses 2 clusters.
